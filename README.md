## 🛠 Використані технології

* **HTML5:** Семантична розмітка (`<header>`, `<main>`, `<section>`, `<article>`, `<form>`, `<footer>`) для покращення доступності (a11y) та SEO-оптимізації.
* **CSS3:**
  * **CSS Variables (`:root`):** Централізована система керування палітрою кольорів (`--red`, `--teal`, `--dark`, `--light`) та відступами (`--gap`, `--side`).
  * **Flexbox & CSS Grid:** Гнучка сітка для карток робіт, послуг та журналу, що автоматично підлаштовується під роздільну здатність екрана.
  * **Mobile-First Approach:** Верстка розроблена спочатку під мобільні пристрої та оптимізована під планшети й десктопи за допомогою `@media (min-width: ...)`.
  * **Checkbox & Radio Hack:** CSS-only реалізація перемикання мобільного меню та фільтрації робіт без використання JavaScript.
* **Google Fonts:** Підключення типографічної системи `Oswald` (заголовки та кнопки), `Open Sans` (основний текст) та `Dancing Script` (акцентний логотип).

## 🎯 Ключові інженерні та дизайн-рішення

### 1. Повністю CSS-driven інтерактивність (Без JS)
* **Мобільне меню:** Реалізовано за допомогою прихованого `<input type="checkbox" id="menu-toggle">` та кнопки `<label class="burger">`. Стан відкриття керується селектором `#menu-toggle:checked ~ .header .nav`.
* **Фільтрація портфоліо:** Смуга категорій (`BRANDING`, `IDENTITY`, `PRINT`, `WEB`, `MOTION`) керується радіокнопками `<input type="radio" name="work-filter">`. Картки приховуються та відображаються завдяки CSS-селекторам стану `:checked` та атрибутам `data-category`.

### 2. Оптимізація та адаптивність UI/UX
* **Вертикальний стек у футері:** Форма `NEWSLETTER` на мобільних пристроях піднімається нагору завдяки `order: -1`. Поле вводу `email` та кнопка `SUBSCRIBE` вишикувані вертикально та розтягнуті на всю ширину (`100%`) для зручної взаємодії на сенсорних екранах.
* **Квадратні пропорції зображень у Журналі:** Для блоку `FROM THE JOURNAL` застосовано комбінацію `aspect-ratio: 1 / 1` та `object-fit: cover`, що гарантує збереження ідеальних пропорцій картинок незалежно від обсягу тексту поруч.
* **Локальне керування медіа-контентом:** Усі зображення завантажуються локально з папки `/img` із застосуванням атрибутів `loading="lazy"`, `width` та `height` для мінімізації CLS (Cumulative Layout Shift).
* **Брендова типографіка:** Скромний розмір елементів у підвалі (13px–14px) та унікальні шрифтові стилізації для логотипів клієнтів (`NOODLE`, `Haley-ann`, `ARED`, `pinewood`, `VILA`, `1870`).
